📘 What is jQuery?▼
jQuery is a fast and small JavaScript library. It simplifies DOM manipulation, event handling, effects and animations with short, readable code.
🎯 How do selectors work?▼
Selectors find elements like in CSS: $("#id") by ID, $(".class") by class and $("p") by tag name.
✨ What effects exist?▼
Show/hide (.show(), .hide(), .toggle()), fade (.fadeIn(), .fadeOut()) and slide (.slideUp(), .slideDown(), .slideToggle()).
🚀 How to create animations?▼
Use .animate() with numeric CSS properties, like width, height, left, top and opacity. Several .animate() calls in a row are queued and play one after another.
🧩 How to change the DOM?▼
Add elements with .append() and .prepend(), delete them with .remove(), and change attributes with .attr().
