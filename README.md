# Assignment #6. jQuery (Selectors, Effects, Animations)

**Student:** Nurzhaubay Dinara Kanatkyzy
**Group:** SE-2526

## Description
A multi-page website that demonstrates jQuery (loaded from a CDN). A navigation bar links all pages.

| Page | Content |
|------|---------|
| index.html | Task 0: Setup, Task 1: Selectors & CSS (.text(), .html(), .css()) |
| effects.html | Task 2: show/hide/toggle, Task 3: fade, Task 4: slide |
| dom.html | Task 5: append/prepend/remove, Task 6: attr(), Task 7: live form (.val(), .text()) |
| animations.html | Task 8: basic .animate(), Task 9: sequential animation, Task 10: combined animation |
| project.html | Task 11: Mini project, Accordion Menu with slide animations |

## How to run
1. Open the live demo link below, or open `index.html` in any browser.
2. Press F12 and open the Console to see the message "jQuery is ready!".
3. Use the navigation bar to switch between the parts.
